# Student Performance Analytics System

## Objective

The objective of this project is to analyze student academic
performance using Python, NumPy, and Pandas.

## Technologies Used

- Python
- NumPy
- Pandas
- Visual Studio Code

## Dataset

The dataset contains student IDs, names, department, marks in
Python, Java, and Mathematics, and attendance percentages.

## Features

- Calculate total and average marks.
- Assign grades based on average marks.
- Identify pass and fail students.
- Calculate subject-wise averages.
- Find the highest and lowest performers.
- Display the top five students.
- Calculate average attendance.

## How to Run

1. Install Python.
2. Install the required libraries:
   python3 -m pip install numpy pandas
3. Keep main.py and students.csv in the same folder.
4. Run the program:
   python3 main.py

## Learning Outcomes

This project demonstrates Python functions, loops, conditions,
NumPy calculations, and Pandas data analysis.
